# DayLight

DayLight is a day planner that turns your classes, meals, and assignments into a realistic
schedule of focused work blocks, breaks, and travel time. It shows what you should be doing
right now and what comes next, and moves work you skip to later.

**Open it here: https://rohit-ful.github.io/daylight/**

## About this repository

This repository only hosts the website through GitHub Pages. It contains the built files
the browser downloads (`index.html` and the `assets/` folder), not the source code, and
it is updated automatically whenever a new version is published.

## Privacy

DayLight has no accounts and no server. Everything you enter is saved only in your own
browser, so it never reaches this repository or anyone else. Clearing your browser data
erases it, and each device keeps its own separate schedule.
